# Hotel Booking Cancellation Prediction using Machine Learning

## Project Overview

This project predicts whether a hotel booking is likely to be cancelled using Machine Learning techniques.

The project follows the complete Machine Learning workflow, including:

- Business Understanding
- Data Exploration
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Building
- Model Comparison
- Feature Importance
- Error Analysis
- Ethical Considerations
- Deployment Challenges

---

## Dataset

Hotel Booking Demand Dataset (Kaggle)

Target Variable:

- is_canceled

0 → Not Cancelled

1 → Cancelled

---

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest

Random Forest achieved the highest accuracy of approximately **80.8%**.

---

## Important Features

The Random Forest model identified the following as the most influential features:

- Lead Time
- Deposit Type
- Market Segment
- Total Special Requests
- Previous Cancellations
